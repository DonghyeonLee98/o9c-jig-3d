# O9C 측정 지그 — 3D 보기

연구실 맥사이언스 O901 지그와 같은 모양(80 × 130.13, 바닥판 + PCB + 셀 블록 + 뚜껑; 11/07부터 셀 블록 6 mm로 얕게)으로 만든 측정 지그들을 브라우저에서 돌려 보는 페이지입니다. 페이지: https://donghyeonlee98.github.io/o9c-jig-3d/

- **S22**: 싱글셀 2 × 2 화소, 25 × 25 유리, 자석 탈착 뚜껑 1.1 t / 2.2 t
- **SB4**: 한 줄 4화소(패턴 B), 1.1 t / 2.2 t 뚜껑
- **MEM**: 메모리 크로스바 6 × 6(핀 12개, 막면 아래), 45 × 45 작은 블록 + 전용 어두운 뚜껑 LID_MEM
- **MEMA**: MEM과 같은 블록 + USB-C·DB9 자리(위치 미정)
- **T2P-N**: KIER 2T 탠덤(0.3 t), 바람개비 — 모듈 4개가 주머니 네 변을 따라 ±1.5 미끄러지고, 자르지 않은 바늘이 V 홈을 따라 앞뒤로, 선으로 PCB에 연결(4선). 몸체 80 × 134
- **T2P-L**: 11/09 뚜껑 PCB 방식 탠덤 랩 지그 — 뚜껑 PCB(72 × 72, 십자 창) 밑면 0906 앞 핀 4개가 KIER 앞 패드를 누르고, 손잡이 2개 7바퀴로 3.5 mm 열림. 아래 PCB·바닥판은 T2P-N과 같음. 선택 이름: T2P-L (뚜껑 PCB).
- **T2P-L3**: 11/10 T2P-L에 중간 전극 접점 2개를 더한 3단자형 — 뚜껑 PCB에 중간 핀 2개(MF·MS)가 웨이퍼 (−x, −y) 모서리 닦기 창의 Ag 패드를 누르고(Kelvin 쌍), 연결 기둥 6개, 아래 PCB O9C_T2P3·바닥판 T2PL3_base. 선택 이름: T2P-L3 (3단자).
- **T2P-P**: 바늘 프로브판, 11/11 r2 — 빔라인 셀 최종 팔 판(r6, 31.6 × 12, 멈춤 손가락) 4개가 웨이퍼 왼쪽·오른쪽에서 W 바늘(32 mm)로 앞 패드를 누르고, 황동 스탠드오프 M3 5 mm + 와셔 0.5(판 바닥 z 5.5)로 아래 PCB O9C_T2P_P에 이어짐. 몸체만 새로(MS2-10 멈춤 핀 4개), PCB·바닥판은 11/10과 같음. 바늘 힘 0.134–0.175 N(웨이퍼 0.3–0.5 t, 계산), 들기 나사 1.73바퀴, 70°까지 빛 가림 0 %, 간섭 0쌍, 실물 시험 0회. 측정·바늘 들림·18° 돌려 치움 세 상태를 버튼으로 바꿔 봄(`?m=T2P-P&s=lifted`). 선택 이름: T2P-P (바늘).
- **HOLD4**: 11/12 키슬리 2400 유지판 O9C_HOLD4 rev C2(4층 160 × 100 × 1.6, 4채널 CH1–CH4, JB-601 바인딩 포스트 20개, USB-C J1, 2 × 4 핀헤더 J2), 주문 전. 윗면·아랫면은 KiCad 3D 렌더 그림(구리·마스크·실크), 부품은 KiCad 3D 모델. 포스트(머리 Ø11 × 높이 12 가정, 축 Ø6, M6 너트 맞변 10)와 USB-C 소켓은 치수 미실측 모형. PCB 그림·부품·포스트 켜고 끄기 가능. `?m=HOLD4`로 엽니다. 선택 이름: HOLD4 (유지판).
- T2P: 웨이퍼는 몸체 턱(z 4.25)에 앉고 뒤 0906은 0.25 mm만 눌림(0.27 N), 바늘 0.35–0.37 N. 받침 고리 안은 11/07에 뺌
- MEM 포고 머리(11/07 새벽)는 MEM·MEMA가 크로스바를 아래에서 찍기로 바뀌어 페이지에서 뺐습니다.

11/07: 11/06의 빔라인식 T2P(가공 황동 블록)는 "가공 금속 부품 없음" 원칙에 따라 T2P-N으로 바뀌어(T2P-A는 11/07에 뺌) 페이지에서 뺐습니다. 나사(나사산·십자/육각 홈·널링 머리), 열압입 인서트, 맞춤핀, 자석, 스프링, 0906 핀, 토글, 바인딩 포스트, BNC는 실물에 가깝게 다시 그렸고, PCB 윗면에는 KiCad 그림(영문 실크, 11/07)을 입혔습니다. MEMA는 자동 보드 설계 전이라 MEM 보드를 보여 줍니다.

11/08: 바닥판 PCB 쪽을 O901 바닥판처럼 홈 두 개로 정리했습니다 — 셀 밑 둥근 홈(S22·SB4·T2P-N Ø40, MEM·MEMA Ø30.9)과 앞 부품 밑 둥근 모서리 사각 홈 하나, 둘 다 깊이 3 mm(관통 아님). 볼트·핀·포스트·BNC 자리는 주문한 PCB 구멍 그대로입니다.

11/12: 오른쪽 아래 '전기 경로 · Electrical paths' 단추(처음엔 꺼짐)로 접점 → PCB 구리 → 포스트·BNC 경로를 넷별 색과 흐르는 점으로 봅니다. 구리는 각 지그의 KiCad 보드 트랙 그대로(T2P-L·L3는 뚜껑 PCB → 연결 기둥 → 아래 PCB까지), 접점·커넥터 위치는 모델 좌표. 토글·점퍼 안쪽 연결과 계측기 쪽 배선은 그리지 않았고, MEMA는 MEM 보드 배선으로 그렸습니다. 가스 포트가 있는 지그가 없어 기체 흐름은 없습니다. `?m=T2P-L3&paths=1`로 켠 채 엽니다.

보기: 분해 슬라이더, 뚜껑 열기(T2P는 모듈 들어내기 / 블록 돌리기), 단면, 층 켜고 끄기, 부품을 누르면 이름과 외곽 치수. 주소 뒤에 `?m=T2P-N&open=1&ex=0.6&sec=1`처럼 붙이면 그 보기로 열립니다.

모델은 연구실 CAD 스크립트에서 만든 형상입니다. 상용 부품 치수 중 일부(유로 단자 슬리브, 스테인리스 판, KIER 뒷면 패드)는 실측 전 가정값이라 가공·주문용 도면이 아닙니다. three.js 0.160.
