# O9C 측정 지그 4종 — 3D 보기

연구실 맥사이언스 O901 지그와 같은 모양(80 × 130.13, 바닥판 + PCB + 셀 블록 + 뚜껑)으로 만든 측정 지그 4종을 브라우저에서 돌려 보는 페이지입니다. 페이지: https://donghyeonlee98.github.io/o9c-jig-3d/

- **S22**: 싱글셀 2 × 2 화소, 25 × 25 유리, 자석 탈착 뚜껑 1.1 t / 2.2 t
- **MEM**: 메모리 소면적 패턴(셀 4개), 1.1 t 뚜껑
- **SB4**: 한 줄 4화소(패턴 B), 1.1 t / 2.2 t 뚜껑
- **T2P**: KIER 2T 탠덤(0.3 t), 뚜껑 없이 빔라인식 텅스텐 바늘 클램프 4개, 4선

보기: 분해 슬라이더, 뚜껑 열기(T2P는 블록 들고 돌리기), 단면, 층 켜고 끄기, 부품을 누르면 이름과 외곽 치수. 주소 뒤에 `?m=T2P&open=1&ex=0.6&sec=1`처럼 붙이면 그 보기로 열립니다.

모델은 연구실 CAD 스크립트에서 만든 단순화 형상입니다(바늘·포스트·스위치·BNC는 외곽만). 가공·주문용 도면이 아닙니다. three.js 0.160.
