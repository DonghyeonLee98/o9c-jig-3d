# O9C 측정 지그 — 3D 보기

연구실 맥사이언스 O901 지그와 같은 모양(80 × 130.13, 바닥판 + PCB + 셀 블록 + 뚜껑; 11/07부터 셀 블록 6 mm로 얕게)으로 만든 측정 지그들을 브라우저에서 돌려 보는 페이지입니다. 페이지: https://donghyeonlee98.github.io/o9c-jig-3d/

- **S22**: 싱글셀 2 × 2 화소, 25 × 25 유리, 자석 탈착 뚜껑 1.1 t / 2.2 t
- **SB4**: 한 줄 4화소(패턴 B), 1.1 t / 2.2 t 뚜껑
- **MEM**: 메모리 크로스바 6 × 6(핀 12개, 막면 아래), 45 × 45 작은 블록 + 전용 어두운 뚜껑 LID_MEM
- **MEMA**: MEM과 같은 블록 + USB-C·DB9 자리(위치 미정)
- **T2P-N**: KIER 2T 탠덤(0.3 t), 바람개비 — 모듈 4개가 주머니 네 변을 따라 ±1.5 미끄러지고, 자르지 않은 바늘이 V 홈을 따라 앞뒤로, 선으로 PCB에 연결(4선). 몸체 80 × 134
- **T2P-A**: 같은 바닥판·PCB에 얹는 두 번째 몸체 — 돌림 블록 + 유로 단자대 황동 슬리브 + 황동 리벳
- T2P: 웨이퍼는 몸체 턱(z 4.25)에 앉고 뒤 0906은 0.25 mm만 눌림(0.27 N), 바늘 0.35–0.37 N. 받침 고리 안은 11/07에 뺌
- MEM 포고 머리(11/07 새벽)는 MEM·MEMA가 크로스바를 아래에서 찍기로 바뀌어 페이지에서 뺐습니다.

11/07: 11/06의 빔라인식 T2P(가공 황동 블록)는 "가공 금속 부품 없음" 원칙에 따라 T2P-N / T2P-A로 바뀌어 페이지에서 뺐습니다. 나사(나사산·십자/육각 홈·널링 머리), 열압입 인서트, 맞춤핀, 자석, 스프링, 0906 핀, 토글, 바인딩 포스트, BNC는 실물에 가깝게 다시 그렸고, PCB 윗면에는 KiCad 그림(영문 실크, 11/07)을 입혔습니다. MEMA는 자동 보드 설계 전이라 MEM 보드를 보여 줍니다.

보기: 분해 슬라이더, 뚜껑 열기(T2P는 모듈 들어내기 / 블록 돌리기), 단면, 층 켜고 끄기, 부품을 누르면 이름과 외곽 치수. 주소 뒤에 `?m=T2P-N&open=1&ex=0.6&sec=1`처럼 붙이면 그 보기로 열립니다.

모델은 연구실 CAD 스크립트에서 만든 형상입니다. 상용 부품 치수 중 일부(유로 단자 슬리브, 스테인리스 판, KIER 뒷면 패드)는 실측 전 가정값이라 가공·주문용 도면이 아닙니다. three.js 0.160.
